# Baddiecore
is a cms you can run in a linux container on your own server. The idea is that users can self host and extend or modify the cms, since they will have the code.

# Glossay.
- you: the agent/ai working on this project
- me: the person talking to the agent
- user: the people/agents that will run this cms on their own servers
- editors: the peopple/agents that will setup pages and put content and copy on to those pages.

# Philosphy
Always favor simplicity, simplicity will be a great benefit as the project grows and gets extended.
Strong combosale primitives, that allow you and the users to extend the project simply.


When running locally use orbstack
